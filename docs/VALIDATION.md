# 0.6.0 验证记录

验证日期：2026-11-11；Windows x64、Electron 45.2.3、Node.js 24.19.0。

## 改动

- 开始学习直接进入题库，默认展示全部考试；默认考试仅作为导入目标，不限制访问其他考试题目。
- 新增考试、年份、难度、来源、学习进度和关键词组合筛选，以及年份、标题排序；无结果时可清除筛选。
- 练习页可通过「筛选 / 换题」跨考试选择篇目，保留各篇答题草稿和作文。写作、听力也可跨考试练习。
- 保留来源信息可选、重复批次提醒、题目去重、每批20页PDF与10万字符、临时气泡和温和陪学。
- 更新启动脚本、使用说明及发行审计。发行采用本机打包、直接上传 GitHub Release，不使用 GitHub Actions。

## 已知限制

不内置试题；AI服务需用户配置，扫描资料需支持图片的模型。真实AI识题与答疑质量未在本轮联测。OCR或改写差异较大时，重复题仍可能需要人工核对。未提供专业发音评分。Windows便携程序尚未代码签名。
