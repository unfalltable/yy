# 精细动漫角色选择

核对日期：2026-11-10。按精细外观、VRM导入便利和陪伴用途筛选。

| 角色 | 适合的方向 | 在Lingo中使用 |
|---|---|---|
| [Manuka / マヌカ](https://booth.pm/zh-cn/items/5058077) · STUDIO JINGO | 本次优先的付费选择；细致动漫面部，作者列有丰富表情、视线和口型 | 作者商品页明确附VRM；自行购买后上传自包含VRM，文件需≤30MB |
| [Shinano / しなの](https://ponderogen.booth.pm/items/6106863) · ポンデロニウム研究所 | 柔和、成熟的动漫造型，适合重视外观改造的用户 | 作者页列FBX、Unitypackage；需要按条款另行导出VRM，不是下载后直接上传FBX |
| VRoid B · VRoid Project / pixiv | 免费直接使用的动漫选择；较细腻的贴图和发丝 | 0.4.0已内置，设置中点击角色缩略图；新安装默认选择 |
| [Seed-san](https://github.com/vrm-c/vrm-specification/tree/master/samples/Seed-san) · VirtualCast | 免费机能服饰动漫选择，材质与表情有特色 | 0.4.0已内置，保留作者要求的署名 |

前两款需在作者商店自行购买；本次提供来源入口。购买前以原作者页面、授权和下载内容为准；原工程的Unity特效、VRChat交互、全部表情预设不会自动带入VRM。Lingo支持VRM 0.x/1.0、自包含贴图和标准表情，模型导出的表情及材质决定实际效果。

免费模型来源：[pixiv官方ChatVRM中的AvatarSample_B](https://github.com/pixiv/ChatVRM/blob/main/public/AvatarSample_B.vrm)、[VRoid模型条款](https://vroid.pixiv.help/hc/en-us/articles/4402394424089)。B不是CC0；Vivi仍按CC0提供。所有内置模型的原始文件保持不变。

动作方面，0.4.0加入真实VRMA待机、说话和鼓励片段，平滑切换并叠加鼠标视线、眨眼和口型。来自[sashii的CC0动作](https://booth.pm/ja/items/6412084)与[へすい/rerofumi的CC0动作](https://booth.pm/ja/items/5527394)，对应摘要与文件校验见[模型与动作许可](../assets/AVATAR-LICENSES.md)。

已有用户的角色选择不会被覆盖。要体验新增角色，请在「学习记录与设置 → 设置与角色」点击「VRoid B · 精细动漫」或「Seed · 机能动漫」。
