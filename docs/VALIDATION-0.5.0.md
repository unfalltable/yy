# 0.5.0 验证记录

验证日期：2026-11-10；Windows x64、Electron 45.2.3、Node.js 24.19.0。

## 本次改动

- 虚拟人物增加学习情绪支持、鼓励、学习计划与当前内容答疑，沿用现有DeepSeek或其他兼容AI设置。陪练依据真实作答、练习计时和近期错题考点交流，不编造成绩，不责备或强迫学习。
- 练习、文章、写作均提供问陪练入口：先预填问题，由用户明确发送。默认附带当前资料节选、题干、选项、所选答案、作文节选与实际进度，可取消本次学习上下文，最近对话仍保留。
- 提示模式不附带未交题的记录答案或完整解析；选择“讲解与答案”后才附带，已交题可结合解析。标明资料记录与AI推断，长资料明确标为节选。
- 增加“鼓励一下”“下一步学什么”与可暂停的专注陪学。可选15/25/45分钟或每日目标；只累计应用前台时间，后台、暂停和休眠跳跃不补时。切页保留本轮，关闭后重新打开保留进度并暂停，需手动继续。
- 默认温和陪伴，过半和完成择机提醒；更主动风格增加四分之一、四分之三里程碑。已提醒状态本机保存，忙碌时延期，不倒序补发多条；关心与目标提醒不自动请求AI。
- 连续答错时给具体支持，连续答对时肯定方法。失败可恢复原问题，停止回答后忽略迟到回复；未配置服务仍可使用标记为本机鼓励的回应。
- 陪练保持固定右下角、单个3D实例和连续本机对话；小窗口对话面板可独立滚动，输入和关闭按钮可达，气泡不会盖住对话控件。
- 状态迁移兼容旧数据，新增陪学进度与提醒风格随备份保存；不修改现有服务凭据。保留20页PDF、10万正文字符、手动分批和不设AI输出token上限的约定。

## 验证

- npm test：38/38通过。新增9项覆盖无剧透提示、讲解上下文、关闭上下文、写作节选、长对话预算、真实统计、鼓励反馈、前台/暂停/休眠计时、里程碑去重与旧数据恢复。
