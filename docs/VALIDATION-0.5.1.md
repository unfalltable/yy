# 0.5.1 验证记录

验证日期：2026-11-11；Windows x64、Electron 45.2.3、Node.js 24.19.0。

## 改动

- 取消题目导入对考试年份、原始试卷名称和原始出处的手填必填限制。三项全空也能在核对题目后入库，不再出现“真题需填写年份、试卷名称与原始出处”的拦截。
- AI提取格式新增逐篇metadata，按文件名、标题、页眉、正文与图片识别年份和试卷名称，原始出处只记录资料中可识别的信息，并返回识别依据；无法确认留空，不编造官方来源。
- 核对页按当前篇目回填来源信息，可修改或清空。用户预填优先；各篇信息独立，避免把不同试卷混用一个年份或出处。
- 来源字段保存user、ai、unknown三种状态。AI识别或缺失的信息显示来源待核实，缺失出处保留上传资料名称及页码定位；不猜年份、不把文件名伪装成官方出处。
- 新标记在本机保存、备份恢复和JSON重新导入时保留；兼容旧AI不返回metadata、空值和数字年份。
- 更新启动脚本、README和发行校验。陪练默认仍为用户所选的温和陪伴，20页PDF、10万字符、手动分批和AI输出不设token上限保持现有设置。

## 验证

- npm test：42/42通过。新增4项覆盖三项全空入库、旧AI返回兼容、逐篇识别信息、手填优先与清空、unknown/ai/user状态、null/数字年份、备份与JSON往返。
- Playwright：24/24通过，覆盖原有学习流程、写作、旧内容清理、角色切换、标题栏、弹窗、文件/文字导入、图片、PDF、答案确认和批次限制。
- 两项新增界面测试验证：三项全空时确认后可入库，重启后原资料与待核实标记保留；AI信息按篇回填、修改和清空后正确保存，没有自动增加AI调用。
- TypeScript与Vite生产构建通过。
- release/win-unpacked/Lingo伴学.exe通过扩展document-smoke：真实DOC/DOCX与内嵌图片解析，经真实IPC及本机模拟HTTP服务返回AI来源信息并回填；12页密集PDF在来源信息完全缺失时仍可入库，保存待核实标记。
- 同一桌面测试通过文字/扫描PDF、本地PDF资源、20页页图发送与保存、超过5万字符正文、原生标题栏、超21页/7张照片拦截、取消和截断处理；请求没有max_tokens或max_completion_tokens。
- 便携包从已验证目录封装；audit-release通过，确认新来源逻辑、4个模型、3段动作、离线PDF资源及版本齐全，不含测试题、源码或开发目录。

检查使用后台Chrome、隐藏Electron、独立临时数据及本机模拟服务，测试窗口与模拟服务已关闭，没有改写现有用户服务配置或调用个人AI额度。真实资料的来源识别准确性仍取决于模型，AI识别不代表官方来源认证，仍需核对。未改变题型支持范围或单批题目数量。
