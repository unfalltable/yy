# Lingo 伴学 0.6.0

- 开始学习直接进入题库，默认展示全部考试；英语二用户也能直接练英语一题目。
- 支持考试、年份、难度、来源、学习进度和关键词组合筛选，按年份或标题排序。
- 做题时使用「筛选 / 换题」选择其他篇目，保留原有作答与写作草稿。
- 保留重复资料提醒与题目去重、来源信息可留空、每批20页PDF及10万字符、连续陪练对话与温和陪学。

下载 Windows.exe 后双击运行。旧版用户先关闭旧版；学习记录仍保存在本机，建议升级前导出备份。

本版不内置试题，需导入自己的资料。AI服务需自行配置；扫描页与照片需要支持图片的模型。OCR差异较大的重复题仍需人工核对。程序尚未代码签名，Windows可能显示发行者提示。

本机验证：54项逻辑测试、42项界面回归，以及打包后桌面与文档导入检查。AI检查使用本机模拟服务，未调用个人AI额度。详情见 docs/VALIDATION.md。
