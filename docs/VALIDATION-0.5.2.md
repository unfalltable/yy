# 0.5.2 验证记录

验证日期：2026-11-11；Windows x64、Electron 45.2.3、Node.js 24.19.0。

## 改动

- 题库封面的01/02原来分别代表考研英语一、英语二，现直接显示“英语一 / 英语二 / IELTS / TOEFL”，调整字号与字体以避免误认为题号。
- 新增本机资料批次指纹：基于本批正文、格式、图片及页码生成SHA-256，忽略文件名与时间；兼容没有指纹的旧资料。重复批次在再次调用AI前提示已有内容，可直接打开，也可主动重新解析补提漏题。
- 新增内容级去重：以目标考试、内容类型、规范化原文、题干和选项识别重复，忽略随机ID、标题、出处、答案和解析变化；处理常见空白、全角字符、题号、选项标号与顺序。保留有含义的大小写差异，写作图片、听力音频参与相应判定。
- 当前批次内部、已有题库以及换ID的JSON导入使用同一去重逻辑。预览显示新增与跳过数量；全部重复时打开已有内容，部分重复仅保存新增题目。
- 已有题目ID、答案、解析、草稿、作答和笔记不被覆盖。相同资料复用原资料，整批重复不保存多余页图；不自动删除原有历史条目。
- 自创阅读若5道中存在重复题，会提示补齐不同题目，保留每批出题的格式约束。资料正文修改后会清除旧重复提示并重新检查。
- 更新启动脚本、使用说明与发行检查。没有修改现有服务配置、上传批次限制或AI输出token设置。
