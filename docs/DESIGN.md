# Lingo 0.6 页面设计

主路径：开始学习 → 跨考试题库 → 选篇练习。题库默认展示全部考试；考试、年份、难度、来源、进度和关键词可组合筛选，支持年份和标题排序。练习中可打开「筛选 / 换题」，切换不丢失各篇草稿。阅读、写作、听力、口语保留在顶部，笔记、错题、生词、报告、设置放在次级菜单。

题库只新增一个主入口「添加题目 / AI出题」。导入窗口先选已有题目提取或文章出题，再选资料与考试，最后核对入库。原题提取默认个人练习；来源信息可留空，由AI按篇识别；无法确认时标为待核实。文章出题默认允许AI改写，原文保留，改写另标。JSON高级导入折叠。

解析、AI请求与最终保存分开；本机读取后用户主动发送，结果可编辑，答案不确定时阻止入库。关闭、取消、接口错误均不写题库。原文件文字和压缩页图在练习页折叠保存，提醒其中可能含答案。真题、个人练习、AI自创、文章使用文字标签，颜色仅辅助。

颜色：纸白#FFFFFF，背景#F7F9FC，正文#20364D，次级文字#62738A，主按钮#286CBA，分隔#E0E7EF。Windows系统字体Segoe UI / Microsoft YaHei，英文正文Georgia。标题64/48px，正文16px，学习字号可调。

使用frontend-design与ui-ux-pro-max技能，保留简洁页面、键盘焦点、响应布局和减少动态效果规范。角色是首页主视觉，不加装饰性统计卡。导入表单提供可见标签、处理进度、取消与明确纠错。

3D角色新安装默认VRoid B，另有Vivi（CC0）、Seed及pixiv VRM示例，支持自定义自包含VRM。答题、提示、录音和AI请求触发表情动作；隐藏页面时暂停渲染，减少动态效果时停止待机摆动。口型按系统TTS状态近似驱动。
