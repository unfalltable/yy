## 本次单批限制

| 项目 | 限制 |
| --- | --- |
| 单文件 / 本批文件合计 | 20MB |
| PDF页数 | 每批6页，可填写页码；留空读取前6页并提醒 |
| 照片 / Word内嵌图片 | 每批6张，Word超量需拆分或转PDF选页 |
| 正文 | 2万字符 |
| 图片编码总量 | 800万字符，约6MB压缩图片 |
| 原题提取 | 最多6篇、合计30题 |
| 文章出题 | 每次1篇、5题、每题4选项 |
| AI输出 | 每次最多8000 tokens；截断则提示拆分 |
| 自动调用 | 不续批、不自动重试，仅用户主动发送 |

这些是请求规模限制，不是金额承诺；实际费用由用户配置的服务、模型和计费规则决定。旧备份仍兼容已有数据，限制作用于新文件与AI导入请求。

## 依赖与已知限制

- npm audit --omit=dev：生产依赖0个已知漏洞。完整审计仍有打包工具链的中危开发依赖项，未采用强制降级修复。
- 当前提取可结构化选择题、写作要求与文章；填空、匹配、多选等暂不支持，会在识别提醒中列出。AI生成仅为阅读单选专项，不是完整考试套卷。
- 照片、扫描件需配置支持图片的模型；AI答案和解析需人工核对。未连接用户真实AI/ASR服务。
- 旧DOC只取正文与文本框，复杂图表/公式/版式可转PDF。图片最长边1600像素，字太小请裁剪。密码PDF需本机解锁。
- 内置题库为空；新建个人模拟和AI自创允许保存，但不能冒充历年真题。旧版擅自内置题继续退休。
- 跟读目前为录音、ASR文字对照，专业音素/重音评分和精确语音口型尚未接入。自定义角色表情取决于模型。
- 3D模型及许可见[来源记录](../assets/AVATAR-LICENSES.md)；没有重新分发“大肥鱼”受限模型。
