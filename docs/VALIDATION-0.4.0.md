# 0.4.0 验证记录

验证日期：2026-11-10；Windows x64、Electron 45.2.3、Node.js 24.19.0。

## 本次改动

- 修复12页PDF已读完却被旧2万字符限制拦截的问题：批次正文上限改为10万字符，导入提示词上限同步为12万字符；PDF仍最多20页，文件合计20MB、照片6张、6篇/30题、图片体积预算及手动分批保持不变。
- Word、粘贴文字、PDF与AI主进程校验使用一致的正文预算。读取失败、取消、AI整理完成和AI失败分别显示实际状态，不再保留过期的“正在读取/识别”提示。
- Windows改用原生标题栏覆盖层，最小化、最大化和关闭按钮始终保留；网页标题栏固定在顶部，弹窗仅滚动正文，关闭按钮保持可见。原生关闭前等待学习记录保存。
- 新增VRoid B与Seed-san两个官方模型，保留Vivi和旧pixiv示例。新安装默认VRoid B，已有用户可在设置中主动切换，不覆盖已有角色选择。
- 接入3段可再分发的CC0 VRMA动作：待机、说话和鼓励。动作平滑过渡、固定根位置，叠加鼠标视线、眨眼、挥手与口型；关闭动态/系统减少动态时暂停。改善近景取景、环境光与材质渲染。
- 设置提供真实缩略图和作者信息；增加Manuka、Shinano作者入口与[角色选择说明](AVATAR-OPTIONS.md)。付费角色需用户自行获取。

## 验证

- npm test：29/29通过，含超过旧2万字符资料、10万字符边界、备份恢复、20页边界和原有题库规则。
- Playwright共28项界面回归覆盖学习、导入、笔记、连续对话、角色、窄屏和键盘操作。全量运行27项通过，鼠标身体角度旧断言与新增待机姿态混合；将应用的鼠标偏移与基础动作分开记录并调好叠加后，相关3项专项复测通过，挥手/静止姿势修正后2项动作专项再次通过。没有仅靠放宽断言跳过功能。
- 新增12页密集结构PDF：提取正文超过5万字符，完整读到第12页末尾，可发送、预览、保存原资料，超过10万字符仍在AI调用前拦截。
- 20页页图可发送、保存并在重新载入后恢复；21页/7张照片、超体积文件、无效AI结果及答案未确认的既有保护继续通过。
- 标题栏在长页面底部保持顶部坐标0；桌面与390像素下弹窗滚到底后关闭按钮仍在视口内、可操作，无横向溢出。
- 两个新模型真实加载；3段动作加载完成、待机帧画面实际变化、说话动作切换、减少动态和关闭动态均验证；旧模型、自定义VRM与失败恢复回归通过。
- TypeScript与Vite生产构建通过。
- release/win-unpacked/Lingo伴学.exe通过document-smoke：真实DOC/DOCX解析、文字/扫描PDF、20页页图、超过5万字符的12页PDF经真实IPC至本机模拟AI并入库、原生标题栏覆盖层、取消和截断处理。确认请求没有max_tokens或max_completion_tokens。
- 同一发行目录通过electron-smoke：沙箱、模拟密钥加密、AI/ASR、角色连续性、鼠标与动态开关、对话持久化。原生窗口关闭后重新启动，验证关闭前刚修改的设置已保存。
- 便携包从该已验证目录封装；audit-release通过，4个模型及3段动作SHA-256与授权清单一致、原生窗口配置、10万字符/20页上限和离线PDF资源齐全，不含测试题或开发目录。

检查使用后台Chrome、隐藏Electron窗口、独立临时数据和本机模拟服务，测试窗口均已关闭。未调用个人付费AI，也未改写现有AI配置。用户原始2010.pdf未作为附件提供，本次用12页密集结构PDF复现字符超限路径；真实识题质量仍由资料和服务模型决定。提取仍每批最多30题，不支持的题型会列入识别提醒。
