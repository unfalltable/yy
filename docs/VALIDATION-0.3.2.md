# 0.3.2 验证记录

验证日期：2026-11-09；Windows x64、Node.js 24.19.0、Electron 45.2.3。

## 本次改动

- 全应用共用一个右下角固定角色，切换首页、题库、练习、笔记和设置时保留同一3D实例。预留稳定的滚动条空间，避免页面滚动条变化使角色横移。
- 对话气泡停留6–16秒后收起，悬停、键盘阅读和朗读时暂停；支持手动收起和再次唤出。修复陪练误用题目卡片横排样式导致文字、按钮挤成竖排的问题。
- 鼠标在应用窗口内驱动头部、视线和轻微侧身；移出或失焦回正，支持动态开关与系统减少动态效果。
- 对话、输入草稿和等待中的回复跨页面连续。已发送记录进入本机学习数据并随备份保存，重开后可继续；长回答完整保留。历史保存与上下文预算见README，AI输出不设置token上限。
- 活跃学习约20分钟后择机关心，输入、录音、对话和弹窗期间延后；可关闭，关心文字不调用AI。

## 验证

- npm test：27/27通过，包含休眠/后台不计时、延后提醒、本地对话预算及完整长回答保存。
- 界面共25项覆盖：19项既有学习/导入回归与6项陪练专项。全量执行后，两项旧测试因新增气泡也使用status而收紧操作toast定位器，复测通过；本地对话持久化及滚动条修复后，3项跨页专项再次全部通过。
- 1480、1000、390像素布局检查通过；气泡自动收起、悬停/键盘暂停、连续招呼计时和隐藏后位置稳定均通过。
- 两款内置VRM真实加载，画面随鼠标变化；关闭动态和系统减少动态效果有效。跨页面只有一个角色canvas，实例和固定位置一致。
- 本机模拟AI验证：请求期间切页仍收到回复；5000字符以上回答保留完整；追问携带前文；重新载入后恢复对话并可继续追问；聊天草稿跨页保留。
- TypeScript与Vite生产构建通过，Windows发行目录生成通过。
- 发行目录release/win-unpacked/Lingo伴学.exe运行electron-smoke通过：沙箱、模拟密钥加密、AI/ASR、本机3D、气泡收起、鼠标联动、跨页坐标/实例稳定、对话持久化与重载。
- 最终便携包从上述已验证目录使用electron-builder --win portable --x64 --prepackaged release/win-unpacked --config.compression=store生成。此包采用快速封装，体积较大；项目默认npm run pack压缩配置未改变。
- node scripts/audit-release.cjs通过：版本、固定角色样式、本地对话代码、两款模型与许可、PDF离线资源和Word线程完整；不含项目测试题、开发目录或vendor示例目录。

检查使用独立临时数据目录、后台Chrome及隐藏Electron窗口和本机模拟AI服务；测试窗口均已关闭，未调用用户付费AI接口。真实AI服务仍需配置，回复质量未使用用户模型验收。鼠标联动限应用窗口内，自定义模型的表情取决于其配置。
