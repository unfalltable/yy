# Lingo 伴学

考研英语一 / 英语二优先的 Windows 英语学习软件，也可切换雅思与托福。

## 打开与学习

双击 [Lingo 0.6.0 桌面版](https://github.com/unfalltable/yy/releases/download/v0.6.0/Lingo-Study-0.6.0-Windows.exe)，或运行根目录「启动桌面版.cmd」。

Windows原生最小化、最大化和关闭按钮始终保留在窗口顶部；页面标题栏固定，弹窗内容单独滚动，关闭弹窗按钮不会被卷走。窗口关闭前等待本机保存。

主流程：**开始学习 → 题库选题 → 练习**。题库默认显示全部考试，英语二用户也可直接练英语一；可组合考试、年份、难度、资料类别、学习进度和关键词筛选，并按年份或标题排序。练习时可点击「筛选 / 换题」，换题保留各篇草稿；默认考试仅用于导入目标，不限制题库访问。题库为空时可添加自己的题目或文章。阅读、写作、听力、口语在顶部切换，笔记、错题、生词、报告和设置放在「学习记录与设置」。英一、英二的听力与口语标为拓展练习。

## 上传与个人题库

在题库点击「添加题目 / AI出题」：

1. 选「提取已有题目」或「文章 AI 出题」，选择目标考试。
2. 上传照片、PDF、Word（DOC/DOCX）、TXT、Markdown，或直接粘贴文字。
3. 本机读取资料，检查文字和页图。PDF 可指定页码，如 1-3,5。
4. 主动点击发送给 AI。逐篇核对、修改题干、选项、答案与解析，确认后才入库。

支持自己购买的模拟题、网上练习及学习文章。真题、个人练习、AI自创和文章分别标记和筛选；答案标明来自资料、AI补全或手动确认。不确定的答案会阻止入库。年份、试卷名称与原始出处均为可选。AI 会按篇从资料正文、标题、页眉、图片或文件名识别并回填，核对页可以修改或清空；用户预先填写的值优先。无法确定也能入库，保留上传资料并标记来源待核实；AI识别信息与自行填写分别标明，识别结果不代表平台认证。原资料仍需核对，程序不会编造官方来源。

文章出题默认允许 AI 调整文章难度与篇幅，也可取消。当前生成范围为阅读单选专项：每次仅1篇、5题，每题4选项，按目标考试设置难度与考点。原文与图片保留供对照，改写材料单独标记。雅思、托福也仅为单选专项，不是完整套卷。纯文章可以不调用 AI，直接保存为精读材料，再选词翻译、朗读、笔记或出题。

单文件与本批文件合计不超过20 MB；文档一次1份，照片一次最多6张，PDF每批最多20页（不填页码时读取前20页）、每批正文10万字符。长文档需分批。Word正文在本机解析，DOCX内嵌位图会一并读取；旧DOC仅提取正文和文本框，复杂排版、公式、图表建议转PDF。PDF保留页图，扫描件及照片需要支持图片的模型。图片会压缩到最长边1600像素，字迹过小时请裁剪后上传。密码PDF需先在本机解锁另存。暂不结构化支持填空、匹配、多选等题型，AI会在识别提醒中列出未覆盖内容。

内置学习题库仍为空；不会用模拟题填充真题库。旧版助手擅自内置的8篇、30道生成题与预设跟读句继续清理，用户主动上传的模拟题与自创练习会保留。可删除个人内容并清理不再使用的原资料，笔记保留。

## 重复资料与题目

题库封面直接显示“英语一 / 英语二 / IELTS / TOEFL”。旧版封面的01、02原本用于表示英语一、英语二，已替换为考试名称。

读取资料后按本批正文、页图及页码计算指纹，忽略文件名。已入库的相同批次会提示“打开已有内容”，不自动再次调用AI；需要补提漏题时可主动选择“重新解析并去重”。PDF不同批次/页码、不同目标考试和文章再次出题可以继续处理，不会被同一文件名拦截。旧资料即使没有指纹也能比较。

确认入库前，按目标考试、内容类型、原文、题干和选项去重；标题、来源、随机ID及解析变化不影响判断。规范化空白、全角字符、常见题号、选项标号和选项顺序，保留词语大小写等可能影响含义的差异。写作图片、听力音频也纳入相应判断，避免只因通用题干相同就误删不同任务。当前批次内部重复也会跳过。

预览显示新增与跳过数量。全部重复时打开原有内容，部分重复时仅保存新增题目；不覆盖旧ID、答案、解析、草稿、作答或笔记。相同资料复用原资料，不额外保存一份页图；全重复批次不保存多余资料。原有历史条目不会自动删除。去重在本机执行；OCR或AI改写造成明显文字差异时可能无法判同，需自行核对。

## JSON导入

折叠区仍支持JSON题库（≤40 MB）。顶层 version=1，contentType 为 past-paper 或 personal-bank，passages 为篇目数组。真题容器只能包含真题；个人题库可包含不同来源。

篇目包含 id、exam（英一/英二/IELTS/TOEFL）、title、subtitle、kind（reading/listening/writing/article）、year、source、difficulty、minutes、paragraphs、questions、provenance。provenance.kind 为 past-paper/practice/article/ai-generated，paper 与 reference 填来源信息；已知真题年份为四位；由导入流程保存的未知年份留空，并通过 provenance.metadata.year=unknown 标记待核实。provenance.metadata 还记录 paper/reference 的 user、ai 或 unknown 状态及识别依据，导出后重新导入和恢复备份会保留这些标记。写作和文章允许 questions=[]。每道选择题含 id、stem、options、answer（从0开始）、skill、explanation、evidence、hints。可选 audio 为受支持音频 data URL。重复ID不会覆盖已有内容；换ID后的重复内容与题目也会跳过。

[空白真题模板](examples/question-bank.json) 不含题目。结构校验不校验版权或来源真实性，目前没有接入真题内容服务。

## 现成3D角色

新增精细动漫 **VRoid B** 与机能风 **Seed-san**，保留 Vivi 和旧版 pixiv 示例，共4款离线角色。新安装默认VRoid B；已有用户可在「设置与角色」点击带缩略图的角色切换，现有自定义模型与选择保留。Seed-san model by VirtualCast, Inc.；VRoid角色由pixiv Inc./VRoid Project提供，具体模型条款见[模型来源与许可](assets/AVATAR-LICENSES.md)。

身体接入sashii与へすい/rerofumi公开的CC0 VRMA动作，包含自然待机、说话手势和答对鼓励；动作平滑过渡，叠加鼠标视线、眨眼、挥手和表情。半身近景优先显示脸部，改进光照、材质与清晰度。开启陪练语音后，口型按TTS播放状态近似驱动；并非专业语音音素对齐。动态开关与系统减少动态效果同时控制身体动作。

追求更精细外观可看[Manuka](https://booth.pm/zh-cn/items/5058077)（作者提供VRM文件）或[Shinano](https://ponderogen.booth.pm/items/6106863)（VRChat/FBX，需另行导出VRM）。两者为作者付费作品，没有代购或内置；按作者条款获取、自行上传≤30MB的VRM。

角色固定在应用窗口右下角，首页、题库、练习、笔记和设置共用同一个角色，切换页面不会重载模型或改变位置。鼠标在应用内移动时，角色平滑转头、移动视线并轻微侧身；移出窗口或窗口失焦后回正。透明角色区域可穿透鼠标，动作可在「角色动态效果」关闭，也遵循系统减少动态效果。

陪练文字使用对话气泡，按内容长度停留6–16秒后收起；悬停、键盘聚焦或朗读时暂停计时。可关闭气泡、打招呼重新唤出，任务提示和答题反馈会再次出现。AI长回答在对话记录中完整保留，气泡展示摘要。

对话、聊天草稿和等待中的回复不因切换页面丢失。已发送的对话记录自动保存在本机，重新打开后也可继续聊，并随学习备份导出；当前聊天输入草稿仅在本次运行中保留。最近200条对话按总计约200万字符滚动保存，优先保留最新完整消息；向AI发送最近约1.4万字符作为对话上下文（超长单条会注明节选），不设置AI输出token上限。

默认开启「陪练关心提醒」：累计活跃学习约20分钟后，择机提醒喝水或放松。后台、失焦、长时间无操作及休眠不计入；输入、录音、打开对话或弹窗时延后。关心文字在本机生成，不调用AI，可在设置关闭。

支持上传自包含VRM 0.x/1.0（≤30 MB）、图片或GIF（≤5 MB；2D）。可用表情取决于模型，失败时可恢复内置模型。角色保存在本机，不发送AI。“大肥鱼”原作者来源已放入设置，其模型许可限定随原插件分发，未另行打包。[模型来源与许可](assets/AVATAR-LICENSES.md)。

## 陪学与答疑

点击角色旁的「问陪练」：可聊学习情绪、请求鼓励、询问知识点或安排下一步。沿用已配置的DeepSeek（如deepseek-flash）或其他兼容服务；不开启自动AI对话。未配置服务时，「鼓励一下」可提供标记为本机鼓励的离线回应。

练习、文章、写作都有「问陪练」入口，先把问题放入输入框，明确发送才调用服务。发送时默认结合当前题目/文章、选项、所选答案、作文节选和实际学习统计；可取消「结合当前学习内容」，但最近对话仍保留。提示模式不附带未交题的记录答案或解析；选择「讲解与答案」后才附带，已交题可结合解析。资料中的AI补全答案会注明性质，回答不代表官方答案。长资料以节选提供，界面完整对话仍保存在本机。可停止回答，失败后可恢复原问题再手动发送。

「专注陪学」可选择15/25/45分钟或当前每日目标，开始、暂停、继续、结束均由自己决定。只累计本应用前台时间，后台不计入；休眠跳跃不补时，重启后保留本轮进度并暂停，需手动继续。该计时表示前台陪学时间，不用于推断其他软件或实际注意力；今日作答/答对次数和练习时长来自已有记录，未开启行为计时则不声称知道练习时长。

默认「温和陪伴」在过半和完成时择机提示，也可在设置选择更主动的目标督促，增加四分之一和四分之三提醒。对话、输入、弹窗和后台期间延后，已提醒的里程碑保存在本机，不补发成串提醒。连续答错时提供小步骤支持，连续答对时肯定解题方法；日常关心、进度提醒和答题反馈在本机生成，用户主动提问、请求鼓励或学习建议才调用AI。陪学记录随学习备份保存。

## 学习与AI

逐题练习、分层提示、解析、断点续做，选词翻译、朗读、高亮、笔记、生词间隔复习，错题原因与基于真实记录的短板分析均已接入。写作草稿自动保存，可主动请求AI建议；听力支持导入音频，没有音频时标明系统朗读。跟读支持录音回放、ASR文字对照，尚无专业音素/重音评分。

在「设置与角色 → AI与语音服务」配置兼容服务：基础地址一般以 /v1 结尾，使用 /chat/completions 和 /audio/transcriptions，支持HTTPS或本机HTTP。对话模型用于文字；可单独填写图片识别模型，否则沿用对话模型。扫描页和照片必须选择支持图片的模型；文字PDF可取消「同时识别本批图片」以仅发送文字。模型需能稳定返回结构化JSON。资料不会自动续批或重试，提取每批最多6篇合计30题，应用不设置AI输出token上限，实际输出由模型和服务端决定。

资料先在本机读取，只有点击发送才上传当前批次文字和已勾选图片。可以取消；失败、截断及无效结果均不改变题库。模型生成的答案与解析需要核对，真实服务的识别与出题质量取决于模型。密钥通过Windows safeStorage加密，不进入学习备份；角色文件不发送。朗读依赖系统语音包，录音依赖麦克风权限。

## 数据与开发

记录保存于应用专用IndexedDB，原资料图片独立保存。备份包含原资料、题目、作答、笔记、写作草稿和陪练对话，旧数据会补齐新增字段。备份上限200 MB，原资料总预算120 MB、最多200份、题库最多500篇。换电脑前先导出备份。录音仅在当前跟读页保留，离开释放麦克风。

Windows、Node.js24+、npm：

```text
npm install
npm run desktop
npm run build
npm test
npm run test:e2e
npm run test:desktop
npm run test:documents
npm run pack
```

[PDF.js](https://github.com/mozilla/pdf.js)在渲染进程本机解析PDF，字体、CMap与解码器随包离线提供；[Mammoth](https://github.com/mwilliamson/mammoth.js)与[word-extractor](https://github.com/morungos/node-word-extractor)在独立受限内存线程处理Word，不需要Office。测试使用独立数据目录和本机模拟AI服务，不读取常规Chrome登录资料或调用个人AI额度；结构占位测试题和文档不进入发行包。
